{{/* Language switcher. The other languages of the current page, and only those. A page that has no translation must not advertise one: linking to `/en/state/` when that file does not exist gets the visitor a 404, which is worse than not offering the switch at all. Hugo's `.AllTranslations` is already filtered to the pages that exist in more than one language. Showing the current language in the list is deliberate — it is a menu, not a pair of arrows, and it is the thing that tells someone the page exists in both languages at all. `Translations` excludes the current one, so the current one is added back by hand. */}} {{- $page := . -}} {{- $current := .Site.Language -}} {{- $translations := slice -}} {{- range .AllTranslations -}} {{- $translations = $translations | append . -}} {{- end -}} {{- if lt (len .AllTranslations) 1 -}} {{/* Only one language for this page: the switcher would be a menu of one. */}} {{- else -}}
