{{/* Breadcrumbs: the visible trail, plus the BreadcrumbList structured data that makes a search result show "Home › Docs" instead of a bare path. Two things were wrong before this rewrite. The JSON-LD built each crumb name with `humanize` on a URL segment, so `/docs/user/errores/` became "Docs › User › Errores" — the slug, not the title a person would recognise, and in whatever language the slug happened to be in. It also started from a hardcoded "Home", so the structured data said "Home" on the English site. The trail here walks the real ancestors instead, so each name is the page's own title, already translated. The `aria-current="page"` item is the current page and is not a link; every earlier crumb is. `x-default` handling is in head.html, with the other languages. */}} {{- $page := . -}} {{- $crumbs := slice -}} {{- range .Ancestors.Reverse -}} {{- if not .IsHome -}} {{- $crumbs = $crumbs | append . -}} {{- end -}} {{- end -}} {{- $structured := slice (dict "@type" "ListItem" "position" 1 "name" (T "breadcrumbs.home") "item" site.Home.Permalink) -}} {{- $pos := 1 -}} {{- range $crumbs -}} {{- $pos = add $pos 1 -}} {{- $structured = $structured | append (dict "@type" "ListItem" "position" $pos "name" .Title "item" .Permalink) -}} {{- end -}} {{- if not .IsHome -}} {{- $pos = add $pos 1 -}} {{- $structured = $structured | append (dict "@type" "ListItem" "position" $pos "name" .Title "item" .Permalink) -}} {{- end -}}
  1. {{ T "breadcrumbs.home" }}
    2. {{- range $crumbs }}
  2. {{- with .Params.shortTitle }}{{ . }}{{ else }}{{ .Title }}{{ end -}}
    3. {{- end }} {{- if not .IsHome }}
  3. {{- if in .RelPermalink "/docs/" }} {{- else if in .RelPermalink "/blog/" }} {{- end -}} {{ .Title }}
    4. {{- end }}
