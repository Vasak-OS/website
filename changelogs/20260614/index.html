Changelogs 14-06-2026 [Alpha]

Dentro de la ultima actualiazacion de VasakOS, se han introducido varias mejoras y nuevas funcionalidades en diferentes componentes del sistema. El gran trabajo realizado va de la mano con la migracion a Wayland buscando un mejor soporte para hardware moderno. A continuación se detallan los cambios más relevantes:

vasak-settings [NUEVO]#

  • Se crea configuracion de atajos de teclado globales con wayfire
  • Se crea configuracion de schemas de color.
  • Se crea seleccion de fuentes para terminal, titulos y apps.
  • Se crean componentes de UI para gestionar estas configuraciones.
  • Se crea seleccion de iconos para tema claro/oscuro.
  • Se crea configuracion de escritorio (fondo, tamaño de iconos, visibilidad de archivos).
  • Se crea configuracion de conectividad (wifi, bluetooth).
  • Se crea configuracion de audio (volumen, mute).
  • Se crea resumen de informacion del sistema (CPU, RAM, GPU, almacenamiento).
  • Se crea configuracion de VPN.

vasak-desktop#

  • Se mejora intefaz de red
  • Se limpia del sistema de configuracion y se delega a vasak-settings para evitar duplicacion de funcionalidades.
  • Los iconos son reactivos a los cambios de iconos del sistema.
  • Mejoras de codigo y limpieza general.
  • Se corrige error en el indicador de bateria que no se actualizaba correctamente.
  • Se corrigen errores minimos de performance y consumo de recursos.
  • Se migra a Wayland para mejorar rendimiento y compatibilidad con hardware moderno.

NOTA: Actualmente el panel del escritorio cuenta conun recuadro negro que se trabajara en futuras releases dado que es un trabajo a realizar en conjunto con Tauri

vasak-desktop-settings#

  • Se elimina configuracion de XFWM
  • Se elimina sesiones de X11
  • Se modifica script de Wayland
  • Se modifica dependencias se agrea wayfire y se elimina xfwm4

vasak-file-manager#

  • Mejoras en el .desktop.
  • Se agrega compatibilidad con la reactividad de los iconos.
  • Se reduce tamaño del binario.
  • Se mejora la reactividad y se eliminan dependencias antiguas

ATENCION: Puede no estar iniciando por una falla en la compilacion

vasak-resonance [NUEVO]#

  • Nueva aplicacion de musica de VasakOS.
  • Soporta formatos comunes como MP3.
  • Interfaz minimalista con soporte para listas de reproduccion.
  • Integracion con atajos de teclado globales para controlar la reproduccion.
  • Integracion con schemas de color y configuracion de fuentes de vasak-settings para personalizacion visual.
  • Persistencia de estado de reproduccion.
  • Soporte para caratulas de album y metadatos de musica.
  • Busqueda automatica de musica en el sistema.
  • Busqueda automatica de letras de canciones.
  • Reprouctor mini flotante para controlar la musica sin abrir la aplicacion completa.
  • Indexacion de musica para acceso rapido.
  • Busca de musica por metadatos (artista, album).
  • Busca de portada de album en la web.
  • Se agregan radios online con soporte para streaming.

vasak-gallery [NUEVO]#

  • Nueva aplicacion de galeria de imagenes de VasakOS.
  • Escaneo automático de directorios del sistema (~/Pictures, ~/Videos, ~/Downloads) al iniciar
  • Grilla adaptativa con miniaturas generadas localmente y almacenadas en caché (~/.cache/vasak-gallery/thumbnails/)
  • Agrupación por mes — las imágenes se organizan automáticamente por fecha de creación
  • Filtros por tipo de media: todo, solo imágenes, solo videos
  • Barra lateral colapsable que muestra todos los años y meses con contenido
  • Navegación instantánea: al hacer clic en un mes, el grid hace scroll suave hasta ese grupo
  • Indicador visual del mes activo
  • Visor de imágenes con zoom (rueda del ratón, 0.5×–8×) y pan (click + arrastre)
  • Doble clic para resetear el zoom
  • Indicador de porcentaje de zoom
  • Navegación entre archivos con botones ← → o teclas de flecha
  • Contador de posición (N / Total)
  • Cierre con Escape o clic en el fondo

vasak-terminal#

  • Se mejora la reactividad de los iconos.
  • Se realizan mejoras en performance y mantenibilidad del código.
  • Se corrige error que no permitia copiar el contenido del terminal.
  • Se agrega notificacion visual de que el contenido ha sido copiado al portapapeles.

Mejoras en librerías y dependencias#

tauri-plugin-vicons#

  • Se actualiza a la última versión para mejorar compatibilidad con nuevos iconos y temas.
  • Se agrega signal de cambio de tema de iconos para que las aplicaciones puedan reaccionar a cambios de configuración.
  • Update to zbase 4.x for improved performance and stability.
  • Se mejora la documentación y ejemplos para facilitar su uso en aplicaciones Tauri.

tauri-plugin-bluetooth-manager#

  • Se actualiza a la última versión para mejorar compatibilidad con nuevos dispositivos Bluetooth.
  • Se corrigen errores en la gestión de conexiones y la detección de dispositivos.
  • Update to zbase 4.x for improved performance and stability.
  • Se mejora la documentación y ejemplos para facilitar su uso en aplicaciones Tauri.

tauri-plugin-config-manager#

  • Se actualiza a la última versión para mejorar compatibilidad con nuevas funcionalidades de configuración.
  • Se corrige la forma de manejar el cache en algunas situaciones para evitar problemas de rendimiento.
  • se eliminan los eprintLn y se modifica por tracing para mejorar la depuración y el seguimiento de errores.
  • Se agregan features especificos de tokio para reducir el tamaño del binario y mejorar el rendimiento.
  • Se modifica dirs-next por home eliminando dependencias obsoletas.
  • Se mejora la serializacion de las configuraciones para evitar problemas de performance y errores de lectura/escritura.

tauri-plugin-network-manager#

  • Se actualiza a la última versión para mejorar compatibilidad con nuevas funcionalidades de red.
  • Se actualiza zbus a la versión 4.x para mejorar rendimiento y estabilidad.
  • Se corrigen parseos de datos de red mejorando los datos generados.
  • Se reutilizan los dbus connections para evitar overhead de crear nuevas conexiones cada vez que se necesitan datos de red.
  • Se elimina codigo muerto.
  • Se corrigen los tipos en JS para mejorar la experiencia de desarrollo y evitar errores de tipo.
  • Se mejora la documentación y ejemplos para facilitar su uso en aplicaciones Tauri.

Errores conocidos#

  • El panel del escritorio muestra con un fondo negro.
  • Si no se dispone de aceleracion 3D basica, algunas aplicaciones pueden no funcionar correctamente.
  • El vasak-file-manager puede no inciar debido a un problema de compilacion.
