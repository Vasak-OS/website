Todo lo que hace falta para instalar VasakOS, mantenerlo actualizado y salir de un problema
cuando algo no funciona. No hace falta saber programar para seguir estas guías, pero sí
estar cómodo abriendo una terminal de vez en cuando: es Arch Linux abajo.

Si vas a contribuir código, la documentación técnica está en
[documentación para desarrolladores](/docs/devs/).
