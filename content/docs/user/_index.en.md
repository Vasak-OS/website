Everything you need to install VasakOS, keep it up to date and get out of trouble when
something does not work. You do not need to know how to program to follow these guides,
though you should be comfortable opening a terminal now and then: it is Arch Linux
underneath.

If you are going to contribute code, the technical documentation is in the
[developer documentation](/en/docs/devs/).
