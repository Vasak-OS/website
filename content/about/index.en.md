VasakOS is a free operating system built on top of **Arch Linux**, with a desktop and a
set of applications of its own. It began inside **Vasak Group** and grows with the
community, around one concrete goal: that a free, open source alternative to commercial
operating systems should exist, without giving up on the experience of using them.

What sets it apart from other distributions is where we put the work. We do not assemble
a selection of applications from other environments: the panel, the file manager, the
terminal, the settings, the gallery, the media player, the keyring and the session
manager are written for this system, in Rust with Tauri and Vue, sharing a single
component library. That is why everything looks and behaves the same way, and why the
interface can be restyled with CSS without recompiling anything.

Underneath it is still Arch: `pacman`, the AUR, the wiki, and the whole ecosystem you
already know.
