Today we published our second plugin for **Tauri**. It is a simple abstraction of something we had been doing in our applications. We managed to extract the code and publish it as a plugin so that any developer can use it. It is called **tauri-plugin-user-data** and it lets you use user data quickly and easily in your applications. It is completely free and open source, so any developer can use it.

## What is User Data?

**User Data** is a library that lets developers use user data quickly and easily in **Tauri**. It only works on Linux and it returns an object with information about the users [the shape of it is subject to change].

## How do I use it?

Everything you need to use it is in the documentation or in its **GitHub** [README](https://github.com/Vasak-OS/tauri-plugin-user-data#README.md). It contains examples of how to use and install it. It is very easy to use and it does not require any advanced knowledge of **Tauri** or **Rust**.

## Where can I find it?

You can find it in its **GitHub** repository and on its **npm** page. It is completely free and open source, so it can be used by any developer. It contains examples of how to use and install it. It is very easy to use and it does not require any advanced knowledge of **Tauri** or **Rust**.
