Today we published our first plugin for **Tauri**. It is a simple abstraction of something we had been doing in our applications. We managed to extract the code and publish it as a plugin so that any developer can use it. It is called **tauri-plugin-vicons** and it lets you use icons quickly and easily in your applications. It is completely free and open source, so any developer can use it.

## What is Vicons?

**Vicons** is an icon library for **Tauri** that lets you use icons quickly and easily in your applications. It is completely free and open source, so it can be used by any developer. It gets the icon from the theme chosen in the operating system.

> > It only works on **Linux**

## How do I use it?

Everything you need to use it is in the documentation or in its **GitHub** [README](https://github.com/Vasak-OS/tauri-plugin-vicons#README.md). It contains examples of how to use and install it. It is very easy to use and it does not require any advanced knowledge of **Tauri** or **Rust**.

## Where can I find it?
