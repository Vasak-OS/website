The people behind **Vendefoul Linux** decided to make a version of their distribution with our desktop. It is in an experimental state for now, because at the moment `vasak-desktop` does not have broad compatibility with other `non-systemd` inits; we will work together anyway to make the desktop integration easier.

## Where can I try Vendefoul Linux with Vasak Desktop

They already have an experimental ISO which you can get from their page on [SourceForge](https://sourceforge.net/projects/vendefoul-wolf-linux/files/Spins%20Comunitarios/Vasak-Desktop/), where you can try it and even install it if you want to.

## Where do I report bugs

For now we are still working on the desktop, its features and its performance, so we will handle every bug report about the desktop itself directly. Any integration problem with the distribution, however, we will work on together with the Vendefoul developers.

## How the work continues

We will work not only to improve the Desktop and VasakOS itself, but also together with Vendefoul and anyone else interested, so that we can offer integrations. Our main focus, though, stays on VasakOS.
