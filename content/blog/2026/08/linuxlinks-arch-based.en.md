**[LinuxLinks](https://www.linuxlinks.com/vasakos-arch-linux-based-distribution/)** published an article about VasakOS, an Arch-based distribution with its own desktop, Wayland and native applications written in Rust.

We're glad they stopped at what makes VasakOS different: a system built from the ground up on Arch, with its own desktop on Wayland and applications written in Rust and Tauri, without relying on themed foreign environments.

**Thank you, Erik Karlsson, for the article** and for including VasakOS in their list of active Linux distributions.

## What you talked about

The article highlights that VasakOS doesn't assemble a desktop from applications borrowed from several environments, but develops its own desktop shell and core applications with a shared design. It emphasizes the Wayland desktop with Wayfire, the Rust + Tauri + Vue stack, the CSS-based interface that can be restyled without recompiling, the file manager with tabs and split-window support, Vasak Settings, the native keyring (AES-256-GCM with Argon2id key derivation), the custom session manager, the PolicyKit authentication agent, Vasak Connect for Android mobile-device integration, and the Calamares-based installer.

It also notes that current Alpha releases are installable, although some functionality remains incomplete while the project matures. That's exactly what we're working on: polishing each piece so VasakOS becomes more complete and stable.

**Thank you, Erik, for reading it and telling it with so much detail.**

## Onward

Having the project reach more international communities makes us very happy. If you try VasakOS and something bugs you, let us know and we'll gladly add it to the improvements list.

**Thanks again** — the door is open for whatever you'd like to try or comment.
