We keep moving forward with the development of VasakOS, and we decided to release Alpha 3, which has many improvements and fixes with respect to the previous version. It is still in **Alpha** state, so it is common to run into bugs or unfinished features. Any report can be made in the repositories and/or in the official communication channels.

## What will I find in Alpha 3?

You can install VasakOS! We added Calamares so that you can install the operating system persistently, the new ecosystem apps such as the terminal and the file manager are already available in the new ISO, and there are some interesting news you can find in the [official changelog](/en/changelogs/20260401/).

## Can I install Alpha 3 on my PC?

Not only do we not recommend installing this version on a PC, given the *possible instability* and the *lack of features*, but to avoid complications we did not include an installer in the ISO that you can get in the downloads area. It is worth pointing out that this ISO is a preliminary version of the operating system and may contain bugs, so it is only recommended for testing and not for daily use. For now this **Alpha** ISO is available for download at the following link: [Download the Alpha 3 ISO](/en/downloads)

## Where do I report bugs or share my experiences?

This is extremely important to us, so you have [the Telegram group](https://t.me/VasakOS) at your disposal to share your experiences or report bugs; it can also be done from the repositories themselves on [GitHub](https://github.com/Vasak-OS).
