Vasak OS is an open source project that seeks to build a modern Linux distribution based on Arch Linux, focused on offering a **complete, coherent and well integrated user experience**.

The goal of the project is to develop an ecosystem of applications and tools that let you use the system in a comfortable and modern way without depending on the terminal all the time, while keeping the power and flexibility of the Linux ecosystem.

![Screenshot of the VasakOS desktop in development, during the project's pre-alpha stage.](https://i.postimg.cc/1XWC31jq/Captura-de-pantalla-20260311-101935.jpg)

The project is currently at an **early development stage (pre-alpha)**, but it already has a working ISO and several system components in development.

In order to keep moving forward we need to add people interested in collaborating.

This is a **non-profit project**, driven by the community and open to anyone who wants to contribute.

---

# What is Vasak OS?

Vasak OS is a distribution based on **Arch Linux** that seeks to offer:

- A **desktop environment of its own**
- Applications designed specifically for the system
- A **consistent visual experience**
- Integration between applications
- Tools that simplify using the system

Several system components are currently being developed, including:

- Its own desktop environment
- System panel
- Application menu
- Notification center
- Applets
- File Manager
- Additional applications that will appear over time

The distribution uses **Arch Linux as its base**, which makes it possible to have a modern and up to date system.

---

# The current state of the project

The project is at a **pre-alpha** stage. This means there is still a lot of work to do, but a working foundation already exists:

![Screenshot of the current state of the project: the in-house desktop alongside the ISO and the file manager.](https://i.postimg.cc/8cyKzg0Q/Captura-de-pantalla-20260311-102113.jpg)

- System ISO
- Desktop environment in development
- Own file manager
- Initial project infrastructure

The ISO is generated using **archiso**, and the system has its own package repositories.

# We want to add contributors

The project is currently being developed by a single person, so adding contributors can make a big difference in how the system evolves.

We are not looking only for experts.

If you are interested in free software and want to learn or to contribute, **your help is welcome**.

# Profiles we are looking for

## Developers

The development of the system applications is done mainly with:

- Tauri
- VueJS
- TypeScript

We are looking for developers interested in collaborating on:

- System applications
- Desktop tools
- New apps for the Vasak ecosystem

You do not have to be an expert, but you do need an interest in learning and contributing.
