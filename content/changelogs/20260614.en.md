This latest VasakOS update brings a number of improvements and new features across different components of the system. The large amount of work done goes hand in hand with the migration to Wayland, aiming for better support for modern hardware. The most relevant changes are detailed below:

## `vasak-settings` [NEW]

* Global keyboard shortcut configuration is created with `wayfire`
* Colour scheme configuration is created.
* Font selection is created for the terminal, titles and apps.
* UI components are created to manage these settings.
* Icon selection is created for the light/dark theme.
* Desktop configuration is created (wallpaper, icon size, file visibility).
* Connectivity configuration is created (wifi, bluetooth).
* Audio configuration is created (volume, mute).
* A system information summary is created (CPU, RAM, GPU, storage).
* VPN configuration is created.

## `vasak-desktop`

* The network interface is improved
* The configuration system is cleaned up and delegated to `vasak-settings` to avoid duplicating functionality.
* Icons react to system icon changes.
* Code improvements and general cleanup.
* A bug in the battery indicator, which did not update correctly, is fixed.
* Minor performance and resource usage bugs are fixed.
* It is migrated to Wayland to improve performance and compatibility with modern hardware.

> NOTE: the desktop panel currently has a black rectangle that will be worked on in future releases, since it is a task to be done together with Tauri

## `vasak-desktop-settings`

* XFWM configuration is removed
* X11 sessions are removed
* The Wayland script is modified
* Dependencies are modified: `wayfire` is added and `xfwm4` is removed

## `vasak-file-manager`

* Improvements in the `.desktop` file.
* Support for icon reactivity is added.
* The binary size is reduced.
* Reactivity is improved and obsolete dependencies are removed

> ATTENTION: it may fail to start because of a build failure

## `vasak-resonance` [NEW]

* New VasakOS music application.
* Supports common formats such as MP3.
* Minimalist interface with playlist support.
* Integration with global keyboard shortcuts to control playback.
* Integration with the colour schemes and font configuration from `vasak-settings` for visual customisation.
* Playback state persistence.
* Support for album covers and music metadata.
* Automatic music search on the system.
* Automatic lyrics search.
* Floating mini player to control the music without opening the full application.
* Music indexing for fast access.
* Music search by metadata (artist, album).
* Album cover search on the web.
* Online radio stations with streaming support are added.

## `vasak-gallery` [NEW]

* New VasakOS image gallery application.
* Automatic scan of system directories (~/Pictures, ~/Videos, ~/Downloads) on startup
* Adaptive grid with thumbnails generated locally and cached (~/.cache/vasak-gallery/thumbnails/)
* Grouping by month — images are organised automatically by creation date
* Filters by media type: everything, images only, videos only
* Collapsible sidebar showing all years and months that have content
* Instant navigation: clicking a month makes the grid scroll smoothly to that group
* Visual indicator of the active month
* Image viewer with zoom (mouse wheel, 0.5×–8×) and pan (click + drag)
* Double click to reset the zoom
* Zoom percentage indicator
* Navigation between files with ← → buttons or the arrow keys
* Position counter (N / Total)
* Close with Escape or by clicking the background

## `vasak-terminal`

* Icon reactivity is improved.
* Improvements in performance and code maintainability are made.
* A bug that prevented copying the terminal contents is fixed.
* A visual notification that the contents have been copied to the clipboard is added.

## Library and dependency improvements

### `tauri-plugin-vicons`

* It is updated to the latest version to improve compatibility with new icons and themes.
* An icon theme change signal is added so applications can react to configuration changes.
* Update to zbase 4.x for improved performance and stability.
* Documentation and examples are improved to make the plugin easier to use in Tauri applications.

### `tauri-plugin-bluetooth-manager`

* It is updated to the latest version to improve compatibility with new Bluetooth devices.
* Bugs in connection handling and device detection are fixed.
* Update to zbase 4.x for improved performance and stability.
* Documentation and examples are improved to make the plugin easier to use in Tauri applications.

### `tauri-plugin-config-manager`

* It is updated to the latest version to improve compatibility with new configuration features.
* The way the cache is handled in some situations is fixed to avoid performance problems.
* The `eprintln!` calls are removed and replaced with `tracing` to improve debugging and error tracking.
* Specific tokio features are added to reduce the binary size and improve performance.
* `dirs-next` is replaced with `home`, removing obsolete dependencies.
* Configuration serialisation is improved to avoid performance problems and read/write errors.

### `tauri-plugin-network-manager`

* It is updated to the latest version to improve compatibility with new network features.
* zbus is updated to version 4.x to improve performance and stability.
* Network data parsing is fixed, improving the generated data.
* D-Bus connections are reused to avoid the overhead of creating new connections every time network data is needed.
* Dead code is removed.
* The JS types are fixed to improve the development experience and avoid type errors.
* Documentation and examples are improved to make the plugin easier to use in Tauri applications.
