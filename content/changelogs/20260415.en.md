Changelogs for the releases published on that date across the repositories. It is still in **Alpha** state, so it is common to run into bugs or unfinished features. Any report can be filed in the repositories and/or through the official communication channels

## `vasak-desktop` (0.6.0)

* The menu now processes `.desktop` files correctly
* A new default wallpaper is added
* The panel reserves space so windows do not maximise underneath it
* The `.desktop` file is fixed so the desktop does not show up in the application menu
* The menu now closes when it loses focus
* The Control Centre now closes when it loses focus
* The logging system is improved so that in production only warnings and errors are persisted
* The shortcut for opening the File Manager from the panel is fixed

## `vasak-terminal` (0.2.1)

* Support for running a command on terminal startup is added
* The terminal icon in the menu is fixed
* The `.desktop` file is fixed so the terminal shows up in the application menu
* Title bar icons for window management are fixed

## `vasak-file-manager` (0.3.0)

* Title bar icons for window management are fixed
* The terminal icon in the menu is fixed
* The `.desktop` file is fixed so the terminal shows up in the application menu

## `vasakos-wallpapers` (0.0.1)

* New wallpapers are added to replace the Cutefish ones
* Cutefish wallpapers are removed
* A new default wallpaper is added
* The wallpapers now have better quality and adapt better to current resolutions

## Arch base ISO [`archiso`]

* Obsolete dependencies are removed
* New VasakOS wallpapers are added
* Cutefish wallpapers are removed
* The in-RAM compression system is improved
* QEMU drivers are added to improve the experience in virtual machines

## `vasak-desktop-settings` (0.2.0)

* The xfwm4 theme is fixed to remove the shadows.
