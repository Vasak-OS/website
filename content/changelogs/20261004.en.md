## VasakOS Beta 1 (2026-10-04)

Today, **October 4, 2026**, we release **VasakOS Beta 1**: the first complete release that installs, works, and is ready for daily use.

---

## Key Features

### Complete Wayland Desktop
- **vasak-desktop** on Wayfire (wlroots) + systemd
- Panel, app menu, notification area, network, sound, brightness, power, screen lock
- Trackpad gestures (3-4 fingers) for workspace switching
- systemd session (uwsm) with compositor plugins

### Native Apps (Working)
- **Vasak Terminal** — tabs, system color palette
- **Vasak File Manager** — tabs, split view, real progress, Ctrl+Z, SMB/sshfs mounts
- **Vasak Settings** — users, date/time, brightness, night light, power, network, sound, appearance, compositor plugins
- **Vasak Gallery** — image viewer and organizer
- **Vasak Resonance** — system audio player with playlists and radio

### Native Graphical Installer: **Vasak Installer**
- Based on Calamares, with our config and install branches
- Written in Rust/Tauri, replaces Calamares with native integration
- Guided or manual partitioning, user, timezone, keyboard
- `vasakos` repo pre-configured and GPG-signed

### Security & Privacy
- **Vasak Keyring** — native Secret Service, AES-256-GCM + Argon2id, PAM auto-unlock
- **Vasak Permissions** — camera, mic, screen, accounts under control
- **Polkit-vasak** — native PolicyKit agent, replaces polkit-gnome
- **Vasak Accounts** — centralized OAuth2 daemon, per-app permissions
- **Vasak Flare Daemon** — freedesktop notifications with persistent history
- **Vasak Keyring** — native keyring with AES-256-GCM + Argon2id

### Real Customization
- Themes with **CSS variables** and **CSS masks**
- Live changes, no recompile, no reboot
- CSS masks for consistent icons

### Own Signed Repository
- `vasakos` repo pre-configured in ISO
- `pacman -Syu` updates Arch base + VasakOS packages
- GPG-signed, automatic verification
