Changelogs for the releases published on that date across the repositories. It is still in **Alpha** state, so it is common to run into bugs or unfinished features. Any report can be filed in the repositories and/or through the official communication channels

## `vasak-desktop`

* The embedded File Manager app is removed
* Performance and graphical consistency fixes
* Fixes in the Network applet
* The desktop's resource usage is reduced
* The build process is improved
* Dependencies are updated

## `vasak-termina` [BETA]

* The new [Terminal app](/en/blog/2026/03/vasak-terminal-a-modern-tauri-based-terminal-for-the-vasak-os-ecosystem/) is made available
* Tabbed sessions
* The integration with the desktop is improved

## `vasak-file-manager` [BETA]

* The new [File Manager app](/en/blog/2026/03/vasak-file-manager-a-new-file-explorer-for-vasak-os/) is made available
* Improvements in navigation and performance
* Improvements in the integration with the desktop
* Tabbed sessions
* Multiple views

## Arch base ISO [`archiso`]

* Calamares is added so the operating system can be installed persistently
* Obsolete dependencies are removed
* The ISO build process is improved

## Calamares

* A bootloader module is added to install GRUB and configure the system boot
* Disk compression is configured to optimise disk space
* The user experience during the installation process is improved

> ATTENTION: for now `calamares` does not work from the menu, and it needs to be run from the terminal with the `sudo calamares` command to start the installation process. This is because we are at an early stage of development and are working to improve the installer integration with the operating system. Any report or collaboration to improve this experience is more than welcome.
