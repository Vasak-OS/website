VasakOS

Un escritorio propio sobre Arch Linux, hecho para que el sistema se sienta tuyo.

Rolling release, Wayland, aplicaciones nativas escritas en Rust y una interfaz que podés modificar con CSS. Libre, gratuito y desarrollado a la vista de todos.

Descargar Alpha Estado del proyecto

Versión Alpha: usable a diario para probar, todavía no recomendada como único sistema. Mirá qué funciona hoy.

Por qué VasakOS

No es Arch con otro fondo de pantalla: el escritorio, las aplicaciones y los servicios están escritos para este sistema.

Base Arch Linux

Rolling release, sin versiones que se queden atrás y con acceso al software más nuevo. Todo el ecosistema y la documentación de Arch siguen valiendo.

Aplicaciones nativas en Rust

Gestor de archivos, terminal, galería, ajustes y el escritorio son aplicaciones propias, no una colección de programas de otros entornos.

Wayland de entrada

Sesión sobre Wayfire administrada por systemd, con bloqueo de pantalla, luz nocturna y control de brillo integrados.

Personalizable con CSS

La interfaz se estiliza con CSS y variables de color. Cambiar el aspecto del escritorio no requiere recompilar nada.

Código abierto, de verdad

Cada componente vive en su propio repositorio público bajo licencia GPL. El historial, los issues y las decisiones están a la vista.

Sin telemetría

El sistema no recolecta datos de uso ni envía información a ningún servidor. No hay cuenta que crear ni servicio al que suscribirse.

Qué incluye VasakOS

Cada pieza es un proyecto propio, con su repositorio público y su versión publicada en el repositorio de paquetes.

CÓDIGO ABIERTO

Todo el trabajo de VasakOS es completamente abierto para la comunidad.

Ver repositorios

Cada componente vive en su propio repositorio público bajo licencia GPL: el escritorio, las aplicaciones, los servicios, los PKGBUILD y hasta este sitio. No hay una parte cerrada que haga funcionar el resto.

Ya seas diseñador, programador o usuario, tu ayuda suma. Desde que instalás VasakOS y reportás lo que no anda, ya sos parte del desarrollo.

  • Forkear, clonar, modificar o mandar un Pull Request.
  • Probar, reportar, sugerir, abrir issues, comentarlos o resolverlos.
  • Traducir, documentar o diseñar iconos y fondos.

VasakOS no compite por consumir menos memoria que nadie. Prefiere gastar los recursos que hagan falta en precargar lo que vas a usar y que el sistema se sienta inmediato, en vez de dejar RAM libre que no le sirve a nadie.

Al estar construido sobre Arch Linux, el sistema es rolling release: no hay versiones que se queden atrás ni una migración grande cada dos años. Las actualizaciones llegan por pacman desde los repositorios de Arch y desde el nuestro.

  • Software siempre actualizado, sin saltos de versión.
  • Parches de seguridad continuos.
  • Repositorio propio firmado con GPG para los paquetes de VasakOS.
